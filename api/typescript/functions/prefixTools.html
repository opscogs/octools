    • prefixTools(tools: Iterable<OCTool>, namePrefix: string): readonly OCTool[]

      Return copies of tools published under namePrefix.

      The prefix is lowercased, and one without a trailing underscore gets one, so "Demo", "demo" and "demo_" are the same prefix; "" renames nothing. Each copy keeps its own func. A name already starting with the prefix counts as published and is kept, so applying it twice changes nothing; a bare name must therefore not start with its own namespace. meta["alias_of"] is prefixed the same way.

      Every whole-word reference to a sibling, in description and in any description of inputSchema or outputSchema (instance data such as enum and default excepted), becomes the sibling's published name. A reference may use the sibling's listed name or, for a sibling already published, its bare form (get_rows for demo_get_rows); an occurrence already prefixed and words that name no sibling stay as they are. The published names are therefore unique, and every whole-word sibling reference names a published tool.

      Throws OCToolError when two tools would publish under one name, when a published name is longer than 48 characters or otherwise breaks NAME_RE, or when an item is not an OCTool. A host dispatches by the returned descriptors' names.
