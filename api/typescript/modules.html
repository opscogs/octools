      @opscogs/octools

      octools: the OpsCogs standard interface for AI agent tools.

      One OCTool descriptor per capability, result envelopes, a conformance validator, and plain-object converters. The public API is exactly this module's exports; each name maps one to one onto a name in the Python package's __all__ (see the package README).
